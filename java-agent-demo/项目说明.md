# Java Agent 示例项目说明

## 📦 项目概述

这是一个完整的Java Agent学习示例项目，展示了Java Agent的多种实现方式和核心功能。

## 🎯 实现的功能

### 1. Premain方式（启动时加载）
- ✅ 支持通过 `-javaagent` 参数在JVM启动时加载Agent
- ✅ 支持三种实现方式：Javassist、ASM、ByteBuddy
- ✅ 自动监控指定包下的方法执行时间

### 2. Agentmain方式（运行时加载）
- ✅ 支持通过Attach API在运行时动态加载Agent
- ✅ 可以重新转换已加载的类
- ✅ 无需重启应用即可添加监控

### 3. 三种字节码操作实现

#### Javassist实现
- 位置：`com.rolin.agent.javassist.PerformanceTransformer`
- 特点：API简单，接近Java语法，适合学习和开发

#### ASM实现
- 位置：`com.rolin.agent.asm.PerformanceTransformer`
- 特点：性能最高，需要了解字节码指令

#### ByteBuddy实现（推荐）
- 位置：`com.rolin.agent.bytebuddy.PerformanceAgent`
- 特点：类型安全，性能接近ASM，易于使用

## 🔑 核心类说明

### PremainAgent
- **作用**：Premain方式的入口类
- **方法**：`premain(String agentArgs, Instrumentation inst)`
- **功能**：根据参数选择不同的实现方式

### AgentmainAgent
- **作用**：Agentmain方式的入口类
- **方法**：`agentmain(String agentArgs, Instrumentation inst)`
- **功能**：运行时加载Agent并重新转换类

### PerformanceTransformer（三种实现）
- **作用**：类转换器，负责修改类的字节码
- **功能**：在方法前后插入监控代码

### TimingAdvice / RuntimeTimingAdvice
- **作用**：ByteBuddy的Advice类
- **功能**：定义方法进入和退出时的逻辑

## 🎓 学习要点

### 1. Instrumentation API
- `addTransformer()` - 添加类转换器
- `retransformClasses()` - 重新转换类
- `getAllLoadedClasses()` - 获取已加载的类

### 2. 字节码操作
- **Javassist**：使用Java语法操作字节码
- **ASM**：直接操作字节码指令
- **ByteBuddy**：使用类型安全的API

### 3. 类加载机制
- 理解Agent如何介入类加载过程
- 了解premain和agentmain的区别

## 🚀 使用场景

1. **APM系统**：应用性能监控
2. **链路追踪**：分布式调用链追踪
3. **代码热修复**：运行时修复bug
4. **性能分析**：方法执行时间统计
5. **安全审计**：方法调用审计

## 📝 注意事项

1. **MANIFEST.MF**：必须正确配置Premain-Class和Agent-Class
2. **类加载器**：Agent使用系统类加载器
3. **性能影响**：只监控必要的包，避免影响性能
4. **工具依赖**：Attach功能需要JDK（不是JRE）
